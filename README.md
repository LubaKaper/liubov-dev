# Liubov

My portfolio site. Live at https://liubov-dev.vercel.app

Plain HTML, CSS and JavaScript, no framework and no build step. Hosted on Vercel.

## What's here

- `index.html`: home page with work, about and contact
- `work/`: case studies (licensing dashboard, Fourth, AlleyCorp relationship intelligence)
- `resume.html`: résumé page with print styles and a PDF download
- `files/`: downloadable résumé PDF
- `style.css`: shared styles
- `main.js`: cursor circle, hero wedge, sticky header, copy-email button

## Run locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.
